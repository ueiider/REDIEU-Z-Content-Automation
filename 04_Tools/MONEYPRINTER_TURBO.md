# MoneyPrinterTurbo

## Purpose
Evaluate MoneyPrinterTurbo as an additional automated content-generation engine.

The user specifically wants to use its useful features rather than ignore the project and rely only on custom scripts.

## Required local audit

- Locate the installation.
- Record version and Git commit.
- Identify configured model providers.
- Identify TTS options.
- Identify image and video source providers.
- Identify subtitle generation.
- Identify music handling.
- Identify rendering engine.
- Identify available automation interfaces.
- Identify licensing and usage restrictions.

## Integration strategy

Do not replace PurffleShorts immediately.

Compare both systems using the same subject and script.

Evaluate:
- Visual relevance.
- Narration quality.
- Caption synchronisation.
- Background music.
- Rendering quality.
- Runtime.
- Cost.
- Automation support.

Keep the best-performing components from each workflow.

## Unknowns
Exact version, configuration, provider credentials and production capabilities remain subject to local inspection.
