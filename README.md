# REDIEU Z — GTA 6 Content Automation

Private project documentation and operational handover repository.

## Mission

Build a free-first, local-first AI content production and publishing system for REDIEU Z, initially focused on Grand Theft Auto VI.

The system should discover interesting topics, analyse source material, generate original English scripts, create narrated and captioned vertical videos, organise finished content, and prepare approved videos for multi-platform publishing.

## Core principles

- Local-first processing wherever practical.
- Prefer free and open-source software.
- Use local Ollama models, especially Nemotron, through OpenCode.
- Preserve existing working tools and pipelines.
- Match footage to narration and the actual subject.
- Clearly distinguish official facts from rumours and speculation.
- Use original, licensed or explicitly authorised footage.
- Human approval before publication.
- Never commit credentials, OAuth tokens or private media.
- Maintain persistent queues, progress records and logs.
