Privacy Policy

Last updated: 2026-11-12

Scope

This Privacy Policy applies to REDIEUZ Content Automation, a local-first content production and publishing preparation system. It describes how information is handled by the operator of that system.

Information processed

The system may process research notes, topics, scripts, narration audio, video files, captions, metadata, queue records, logs, review status, platform account identifiers, and publishing status records. It may also process OAuth client details and access or refresh tokens for platforms that the operator configures.

OAuth authorization

YouTube publishing uses Google OAuth for a desktop application. The authorized Google account grants the application permission to upload videos to the connected YouTube channel. The OAuth application is configured for external users and may be used in testing mode, which can require approved test users and can limit token lifetime or publishing behavior.

OAuth client files and token files are stored locally by the operator. They are not intended to be committed to version control or published on this website.

Platform tokens

Platform tokens are used only to perform publishing actions requested by the operator, such as uploading or queueing an approved video. Tokens are stored in local application or profile storage. Token handling, expiry and revocation depend on each platform and on the operator's local configuration.

Publishing and content data

Finished videos and metadata are prepared on the operator's local machine. A publishing queue may copy or reference approved media from a configured local media directory. Publication to a platform sends the content and metadata required by that platform's API.

The system is designed to require human approval before publication. Publishing actions are operator-controlled rather than automatic consequences of rendering.

Storage and location

Production data is stored locally on the operator's machine. This public website does not host production data, media, credentials, queue contents or configuration. The website is separate from the private publishing dashboard.

Data sharing

REDIEUZ Content Automation does not sell personal data. Data is shared with a platform only when the operator requests a publishing action using that platform's API. Platform providers process that data under their own terms and privacy policies.

Retention and deletion

The operator controls retention of local production files, logs, queues, review packages and credentials. Tokens can be revoked through the relevant platform, and local credential files can be removed by the operator. This website does not retain user-submitted personal data.

Children's privacy

This system and website are not directed to children. They are intended for content production and publishing workflow documentation.

Changes to this policy

This Privacy Policy may be updated as the system changes. The "Last updated" date at the top of this page indicates the current version.

Contact

Questions about this policy or the project can be raised through the project's GitHub repository issues.
