# Other Platform Integrations

## Instagram
Investigate Meta Graph API and Instagram professional-account publishing requirements.

Verify:
- Professional account eligibility.
- Connected Facebook Page if required.
- App permissions.
- Publishing permissions.
- Media container requirements.
- Reels publishing support.

## Facebook
Investigate Meta Graph API publishing requirements.

Verify:
- Page ID.
- Page access token.
- Required permissions.
- Video upload endpoint.
- Reels publishing support.

## TikTok
Investigate TikTok Content Posting API.

Verify:
- Developer application.
- OAuth authorization.
- Required publishing scopes.
- Creator/account eligibility.
- Direct Post approval requirements.
- Upload and publishing status.

## General rules

- Do not invent API permissions.
- Do not assume credentials are available.
- Keep tokens local.
- Test with controlled visibility.
- Document approval and app-review requirements.
- Do not publish without user approval.
